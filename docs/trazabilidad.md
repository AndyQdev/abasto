## Cómo correr todas las pruebas

```bash
pnpm test            # TypeScript: servicios NestJS, apps web y paquetes
pnpm test:pedidos    # Spring Boot (JUnit + ArchUnit)
pnpm test:catalogo   # Laravel (Pest + Deptrac)
pnpm test:ml         # Python (pytest)
pnpm e2e             # punta a punta con Playwright (necesita pnpm todo)
pnpm arquitectura    # capas: ArchUnit, Deptrac y dependency-cruiser
cd apps/app && npm test   # la app Expo (Jest)
```
